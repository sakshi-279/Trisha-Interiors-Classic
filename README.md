## 📁 Editions & File Structure

This project contains **two distinct design editions**, allowing you to choose the vibe that best matches your client presentation:

### 1. Classic Luxury Edition
- **File**: `index.html` (with `styles.css` & `script.js`)
- **Aesthetic**: Warm architectural minimalism, champagne gold accents, rich comprehensive sections, live budget calculator, and full Vastu grid.

### 2. Dramatic Minimalist Noir Edition
- **File**: `dramatic.html` (with `dramatic.css` & `dramatic.js`)
- **Aesthetic**: High-fashion architectural editorial, chiaroscuro mood lighting, cursor spotlight glow, interactive Vastu cardinal dial, bold minimalist statements, and dramatic before/after reveal.

## 🚀 How to View Locally

You can open the website in any browser:

1. **Directly via File Explorer**:
   Navigate to `C:\Users\Admin\.gemini\antigravity\scratch\trisha-interiors` and double-click `index.html`.

2. **Via Local Development Server (Optional)**:
   In your terminal or PowerShell:
   ```powershell
   cd C:\Users\Admin\.gemini\antigravity\scratch\trisha-interiors
   npx serve .
   # or: python -m http.server 8000
   ```
   Then open `http://localhost:8000` or the port displayed.

## 🌐 Deploying to Production (Free)

The site is 100% static and zero-dependency, meaning you can host it immediately on:
- **Netlify**: Drag & drop the `trisha-interiors` folder to [Netlify Drop](https://app.netlify.com/drop).
- **Vercel**: Deploy with one click via `vercel` CLI or GitHub.
- **GitHub Pages**: Push to a repository and enable Pages in repository settings.
- **Firebase Hosting**: Run `firebase deploy --only hosting`.
